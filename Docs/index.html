Lumiform Colorpicker Design Doc & Roadmap

Real-Time 3D Color Picker & Light Simulator for Photoshop 2025

Project Overview & Vision

Lumiform Colorpicker is an interactive 3D color preview and light simulation plugin designed for digital painters, concept artists, and illustrators. It addresses the fundamental flaw of 2D flat color pickers: muddy, unnatural shadows and chalky highlights caused by naive value shifts.

The Problem in 2D Painting

When artists pick shadow colors using traditional 2D swatches, they typically shift brightness down toward black or desaturate. In reality, shadows are illuminated by ambient skylight and ground bounce light.

Failure Mode: Desaturated, dead shadows lacking ambient color temperature and form clarity.

The 3D Solution

By mapping the local base color onto a real-time lit 3D sphere, artists immediately see how warm sunlight, cool sky fill, and ground bounce naturally interact. The artist clicks directly on the sphere or the value ramp to paint with physical light.

Outcome: Vibrant, accurate lighting ramps with instant one-click brush application.

Core Design Pillars

1. In-Panel 3D Viewport

Three.js WebGL viewport rendering up to three grounded spheres in fixed near/mid/far slots, with a fixed camera, a per-sphere size slider, and Orbit/Height light-direction sliders.

2. Physical Light Simulation

Directional key light with 3-zone ambient environment (Sky, Horizon, Ground bounce) and seven calibrated Time-of-Day presets, each with its own Haze amount.

3. Live 5-Value Swatch Ramp

Mathematically accurate real-time swatches: Highlight, Half-Tone, Terminator, Core Shadow, and Bounce Light.

Photoshop Add-on Runtime (UXP Panel + Local WebView)

UXP panels do not provide WebGL, so the dockable Photoshop panel hosts the built Three.js app in a local UXP WebView (plugin:/web/index.html). WebView2 on Windows and WKWebView on macOS provide the WebGL context, so the existing renderer, shaders, and eyedropper run unchanged.

  • Panel shell: plugin/index.html — full-size WebView plus loading/error overlays.
  • Host relay: plugin/main.js — reads/writes app.foregroundColor, coalesces rapid samples, polls external changes.
  • WebView bridge: src/bridge/WebViewPhotoshopBridge.ts — implements the same bridge interface as the mock.
  • Package: npm run plugin → release/Lumiform-Colorpicker-1.1.0.ccx.

The web app is inlined into one HTML file to avoid module/asset resolution on the plugin:/ origin. Requirements: Photoshop 2025 (26.0+) or 2026; install via the .ccx, UXP Developer Tool, or the Photoshop Plug-ins folder. See Docs/PHOTOSHOP.md.

3D & Lighting Physics Engine

3-Zone Ambient & Directional Key Light

Realistic illumination is represented by combining directional sun rays with hemispherical and ground-reflected scatter:

I_total = I_key * max(0, N · L) + I_ambient(N) + I_specular

Where ambient lighting interpolates across three vertical bands:

  • Sky (Zenith): Affects surfaces facing upward ($\hat{N}_y > 0$).
  • Horizon: Affects lateral glancing angles ($\hat{N}_y \approx 0$).
  • Ground Bounce: Affects downward undersides ($\hat{N}_y < 0$).

Surface Finish Modes

The sphere material dynamically switches between three physical finishes:

  • Matte (default): Roughness 1.0, 0% Reflectance. Pure Lambertian diffuse (skin, chalk, matte fabric).
  • Satin: Roughness 0.45, 40% Reflectance. Broad, soft GGX highlight (leather, smooth plastic).
  • Glossy: Roughness 0.08, 95% Reflectance. Tight GGX highlight with Fresnel edge (metal, wet surfaces).

Seven Time-of-Day Presets

Each preset restores its own key light, sky, ground albedo, horizon haze, and calibrated Haze amount. Haze is expressed as a fraction of the maximum: 0% is clear air, the preset value reproduces that phase's measured atmosphere, and 100% is maximum fog.

Color Controls & Swatch Ramp

Self-Contained In-Panel Controls

The panel includes dedicated HSB sliders and a Hex input:

  • Hue: 0° to 360° gradient slider.
  • Saturation: 0% to 100% dynamic saturation gradient.
  • Brightness: 0% to 100% value slider.
  • Hex Input: Bidirectional hex sync with validation.

Decoupled Input Guarantee: The 3D sphere is driven strictly by panel controls to prevent unwanted canvas feedback loops while painting.

Analytical 5-Value Swatch Calculation

Rather than reading arbitrary screen pixels, the 5 value swatches are evaluated mathematically from the lighting model at canonical surface normal angles:

Highlight Half-vector $\hat{H} = \text{normalize}(\hat{L} + \hat{V})$
Half-Tone Surface normal at $45^\circ$ toward light vector $\hat{L}$
Terminator Normal perpendicular to light ($\hat{N} \cdot \hat{L} = 0$)
Core Shadow Normal facing opposite light before ground bounce
Bounce Light Normal pointing directly down toward ground reflection

Depth, Atmosphere & Multi-Sphere Composition

The preview uses three fixed depth slots. The goal is for concept artists to compare how the same lighting behaves at near, mid, and far distances, and to sample atmosphere-shifted colors directly from the render. Complete

1. Three Depth Slots

Near sits closest to the camera, Mid at mid distance and Far near the horizon. All spheres start at the same base radius and rest on the ground; perspective creates the initial size difference, and each sphere can then be scaled independently.

2. Aerial Perspective

Single-scattering depth fog that fades each surface toward the background actually behind it: sky with a smooth horizon haze band above the eye line, phase-tinted ground haze below. Contrast and saturation fall off with distance, so the far sphere dissolves into the scene instead of turning into a pale disc.

3. Per-Sphere Colour & Size

Each sphere has its own albedo and size. Link Colours and Link Size apply one edit to every enabled sphere, while unlinked edits affect only the selected sphere. Hidden spheres keep their values for restore-on-re-enable.

Composition Slots

Slot Internal id On-Screen Role Atmosphere Shadows
Near center Largest sphere, primary subject, closest to camera Exactly clear: colour reference Strongest contact AO and drop shadow
Mid right Secondary sphere, partially receding Partial haze, softened contrast Softer, shorter-looking shadow
Far left Smallest sphere near the horizon line Strong haze, atmospheric color shift Faint shadow, absorbs into ground haze

V1.1 behaviour. Near / Mid / Far are three-state toggles that carry visibility and selection. The last enabled sphere cannot be hidden, re-enabling restores that sphere's previous colour and size, and Link Colours / Link Size keep every enabled sphere on the selected value. The v1.0 count control, Delete and separate selector row no longer exist.

Controls

Control Behavior
Near / Mid / Far Three-state toggles. Off enables and selects the sphere; on-but-unselected selects it; selected hides it. The last enabled sphere cannot be hidden. Hiding the selected sphere falls back in Near → Mid → Far order, and re-enabling restores the colour and size it owned before it was hidden.
Link Colours / Link Size Each link adopts the selected sphere's value when enabled and keeps applying subsequent edits to every enabled sphere. Disabling a link keeps the shared value so spheres can diverge. Re-enabling a hidden sphere while a link is on joins the shared value.
Size 20%–100% of the base radius. Applies to the selected sphere, or to every enabled sphere when Link Size is on. Scaling pivots on the sphere's bottom-center so it stays grounded; the camera does not move.
Albedo & H · S · B The merged Spheres panel exposes the selected sphere's albedo chip and hex, with the HSB sliders behind a closed disclosure. The swatch ramp follows the selected sphere; its header names that sphere and shows an albedo dot.
Eyedropper Samples the final, atmosphere-affected pixel from any sphere, so haze-shifted colors can be sent directly to Photoshop's brush.
Time-of-Day Presets Seven calibrated phases: Early Morning, Morning, Midday, Afternoon, Near Sunset, Golden Hour, Night. Selecting one restores its key light, sky, ground albedo, and Haze amount. The Haze slider moves to that preset's calibrated value (Midday 3% through Golden Hour 70%).
Haze 0% clears the atmosphere, the preset value reproduces that phase's measured depth fade, and 100% reaches maximum fog. The near sphere stays exactly clear; mid and far spheres dissolve into the horizon band. Manually changing the sun keeps the current Haze; selecting a preset resets it.
Atmosphere Distance-based single scattering applied consistently to spheres and ground. The airlight is the local sky/ground behind each pixel, with a smooth horizon haze band; the ground-to-sky transition is spread across the band so hazy spheres do not show a seam at the eye line.

Implementation Notes

The ground shader accumulates drop shadows and contact AO across all visible spheres. Each sphere renders with its own material instance so albedo and depth treatment stay independent. Atmosphere is evaluated per fragment as single-scattering depth fog: the surface is attenuated by distance and mixed toward the background behind it (sky along the view ray with a horizon haze band, or the phase's ground haze below the eye line). Distant objects therefore desaturate toward what is actually behind them and can never become paler than that background. The near sphere sits inside the fog-free range so it stays an exact colour reference. The ground-to-sky airlight transition is spread over the horizon band rather than snapped at the eye line, so a hazy sphere reads as one form instead of two colours. Each preset owns its calibrated Haze amount, and selecting it resets the slider. Picking reads the final framebuffer, which means the sampled color already includes haze. The analytical swatch ramp follows the selected sphere, including its depth haze, and labels itself with that sphere's name and albedo dot.

Behaviour Rules

The detach model

Presets are starting points, not modes. Clicking one applies it and moves every lighting slider to its values. Moving any of Orbit, Height, Terminator, Haze, Light colour or Ground colour clears all seven buttons - the state is custom, but no Custom button exists to represent it. The label then reads Near Sunset · edited ↺ and the thumb stays parked. ↺ or any preset button re-applies the calibrated preset.

Sphere toggles

Near, Mid and Far carry both visibility and selection. Off → clicking enables and selects. On but unselected → clicking selects. On and selected → clicking disables. The last remaining sphere refuses to turn off, and re-enabling restores that sphere's own colour and size rather than resetting it.

Ramp indicator

The ramp reports the sphere it is computed for with a read-only chip and an albedo dot, so two spheres can be compared under identical lighting. The five values remain analytical - evaluated from surface normals - never sampled from screen pixels.

Guide and writes

The guide is a full-panel overlay, not a section: it covers header, canvas and status bar, and returns via Back, Esc or the backdrop. It carries the GitHub row. Every external link goes through the host bridge, because window.open is unreliable inside a plugin WebView.

V1.2 - Native Photoshop Skin

V1.2 makes the panel read as a native Photoshop panel across all four built-in themes. It is a chrome-only reskin: the renderer, camera framing, lighting, atmosphere and swatch mathematics stay untouched. The time-of-day gradient is the one intentional exception and stays exactly as it is. In Progress

Objective

Match Photoshop's neutral gray chrome: flat surfaces, 1 px dividers, ~2 px radii, compact 22-24 px controls, Segoe UI, monochrome line icons and a sampled neutral selection tint. Follow Black, Dark Gray, Medium Gray and Light Gray live through a UXP host relay, with a manual Appearance override.

Non-goals

No renderer, framing, lighting, atmosphere, shader or swatch-math changes. No new controls or presets. No custom UIColors.txt themes and no Gray/Blue Highlight detection - those are not exposed to plugins. No change to the time-of-day gradient, thumb or geometry.

4.1 Theme probe Built, awaiting captures

What it measures

A throwaway UXP panel, not part of the product and sharing no code with plugin/. It reports document.theme.getCurrent(), live onUpdated values, every computed --uxp-host-* variable with a swatch, app.appSkinInfo colour roles, the prefers-color-scheme result and Photoshop/UXP versions.

It writes one theme-<name>.json snapshot per theme into its own PluginData folder, so the palettes are frozen from exact values, not screenshots.
Source: tools/theme-probe/ · Package: npm run probe:package · Output: Lumiform-ThemeProbe-1.0.0.ccx

How to capture

  1. Copy tools/theme-probe/ into Photoshop's Plug-ins folder, or install the probe .ccx, then restart Photoshop.
  2. Open Plugins ▸ Lumiform Theme Probe and float it at about 460 x 920.
  3. Open Photoshop ▸ Settings ▸ Interface ▸ Color Theme.
  4. Select Black, Dark Gray, Medium Gray and Light Gray in turn; each switch saves a JSON snapshot.

The four palette columns stay pending until these captures land. They are not guessed.

Risks and fallbacks

Documented-API risk

document.theme is not officially documented for Photoshop. The probe verifies it on the target build; the manual Appearance row is the fallback.

Four palettes

Medium Gray is sampled now. The probe captures Black, Dark Gray and Light Gray so the other three token sets are not guessed.

Light-theme contrast

Light Gray will need small gray adjustments for readable text. That is the one approved deviation from an exact match.

Time gradient

It stays exactly as-is, including thumb and geometry. It is the one intentionally non-Photoshop element; the surrounding row is themed.

Host variables

Use --uxp-host-* for the host shell and probe calibration, not as the WebView's runtime colour source.

Scope

No renderer, framing, lighting, atmosphere or swatch-math changes. If a task needs one, stop and ask.
